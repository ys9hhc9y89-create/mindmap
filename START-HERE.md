# Übergabe an lokales Codex

## Schnellstart auf dem Mac

1. ZIP-Datei entpacken.
2. Den Ordner `schoolhelper-mindmap` in der Codex-App als lokales Projekt öffnen.
3. Einen neuen Chat in diesem Projekt starten.
4. Folgenden Auftrag einfügen:

> Lies zuerst `AGENTS.md` und `HANDOFF.md` vollständig. Übernimm den vorhandenen Projektstand und setze die GitHub-Veröffentlichung fort. Erstelle beziehungsweise verwende eine öffentliche Organisation `schoolhelper` oder einen gemeinsam festgelegten Ersatznamen, veröffentliche das Repository als Open-Source-Template mit GitHub Pages und gib erst nach bestandenen Tests die Live-URL aus. Bewahre alle Datenschutz- und Offline-Anforderungen unverändert.

Alternativ im Terminal:

```bash
cd /Pfad/zu/schoolhelper-mindmap
codex
```

Danach denselben Auftrag eingeben.

Die lokale Codex-Sitzung benötigt nicht den vollständigen ursprünglichen Chat. `HANDOFF.md` enthält den belastbaren Arbeitsstand, die Entscheidungen und alle offenen Schritte.
