# Gedankenraum – Mindmap

Eine kostenlose, quelloffene Mindmap-Web-App für Unterricht und Schule.

Gedankenraum läuft direkt im Browser, speichert Mindmap-Inhalte nur lokal und funktioniert nach dem ersten Laden auch offline. Es gibt keine Konten, keine Cloud-Synchronisierung, keine Werbung und kein Tracking.

## Nutzung

Die Live-Demo kann über GitHub Pages geöffnet werden. Die Dateien werden einmal geladen und anschließend vom Browser lokal verwendet. Mindmaps bleiben auf dem jeweiligen Gerät. Für wichtige Arbeiten zusätzlich `Datei sichern` verwenden.

## Entwicklung

Die App besteht aus Standard-HTML, CSS und JavaScript und benötigt keine Build-Schritte oder externen Laufzeitabhängigkeiten.

```sh
python3 -m http.server 4173
```

Danach `http://127.0.0.1:4173/` öffnen.
