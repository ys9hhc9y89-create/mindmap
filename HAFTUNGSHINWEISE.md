# Haftungshinweise

Gedankenraum wird kostenlos und ohne Gewähr für eine bestimmte Eignung oder ununterbrochene Verfügbarkeit bereitgestellt.

Die Nutzung erfolgt auf eigene Verantwortung. Für wichtige Arbeiten sollten zusätzlich JSON-Sicherungen angelegt werden. Eine Haftung für Datenverlust wird, soweit gesetzlich zulässig, ausgeschlossen.

Die Haftung für Vorsatz, grobe Fahrlässigkeit, Schäden an Leben, Körper oder Gesundheit sowie für Fälle, in denen eine Haftungsbegrenzung gesetzlich unzulässig ist, bleibt unberührt.
