# Datenschutzhinweise

Stand: 21. September 2026

## Lokale Mindmap-Daten

Gedankenraum verarbeitet Titel, Themen, Farben, Positionen und importierte Dateien ausschließlich im Browser auf dem jeweiligen Endgerät. Die automatische Speicherung erfolgt im lokalen Browserspeicher. JSON-Import, JSON-Export und die Druck-/PDF-Ausgabe werden clientseitig ausgeführt.

Die Anwendung verwendet keine Benutzerkonten, Datenbanken, Cookies, Analyse-, Werbe- oder Trackingdienste und überträgt keine Mindmap-Inhalte an den Betreiber.

## Öffentliche GitHub-Pages-Demo

Beim Aufruf der öffentlichen Demo werden technisch notwendige Verbindungsdaten an GitHub als Hosting-Anbieter übermittelt. Dazu können insbesondere IP-Adresse, Zeitpunkt, Browser- und Gerätedaten sowie technische Protokolldaten gehören. Diese Verarbeitung erfolgt durch GitHub und nicht durch die Mindmap-Anwendung. Maßgeblich sind die Datenschutzinformationen von GitHub.

Wer auch diesen Abruf vermeiden möchte, kann die Anwendung lokal herunterladen und offline verwenden.
